10 HTML Tags Used: 
<html>, <head>, <body>, <title>, <nav>, <a>, <div>, <header>, <main>, <section>, <h1>, <h2>, <p>, <strong>, <img>, <footer>, <table>, <thead>, <tr>, <th>, <tbody>, <td>

5 CSS Properties Used:
background-color, color, background-attachment (for parallax), transition (for scroll reveal), transform (for animations).

Bootstrap Features:
Used the Responsive Grid System (container/row/col), Navbar for navigation, and Utility classes (mt-5, display-3).

JavaScript Implementation:
I used the Intersection Observer API to detect when a user scrolls to a section and apply a 'visible' class, triggering a smooth fade-in and slide-up animation for my personal story.
